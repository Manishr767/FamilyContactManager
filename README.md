# Family Contact Manager

This repository is currently a starter project for a family contact management application.

## Project status

The repository currently contains only an initial README and does not yet include an implemented application.

## Possible direction

A future version could support:

- Adding and editing contacts
- Searching contacts by name
- Organizing contacts into groups
- Saving contact records locally or in a database
